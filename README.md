# 可可嫑记

> 百宝箱：公式、灵感、记忆卡、错题本，考研一个 app 管够。

一个装在自己手机里的离线学习小工具，给考研复习用的：公式随手拍下来存着，
想到什么一句话记下来，错题和没解决的问题都有地方放。

- **完全离线**：不联网、无账号、无云同步，数据只在这台手机上
- **单人自用**：没有多用户、没有分享、没有排行榜
- **能带走**：全部数据可以导出成一个 zip，换手机时再导回去

## 现在能用的功能

| 入口 | 状态 |
| --- | --- |
| 公式手册 | 能用：按科目分，可以拍照存公式 |
| 灵感记录 | 能用：按天排列的时间线，标题选填，可打标签、可置顶 |
| 记忆卡片 | 能用：只做「今天 / 明天」的简单复习，不做间隔重复算法 |
| 错题本 | 能用：多一栏「我当时错在哪」 |
| 问题收集箱 | 能用：没写答案的就是「待解决」，回填后进归档区 |
| 考点大纲 | 待开发，点进去是占位页 |

顶部还有一个全局搜索，标题、正文、科目名、标签都能搜。

## 数据只有两张表

这是整个项目最重要的一条设计决定：**六个功能不是六套系统，而是同一张卡片
的不同视图**，加功能不需要改表、更不需要新建表。

```
subjects   科目（运筹 / 高数 / 线代 / 数据库 / 408，可以在 app 里增删改）
cards      卡片（type 区分公式 / 灵感 / 记忆 / 错题 / 问题）
```

几条不能破的规矩：

- 图片在数据库里**只存文件名**，真实路径运行时解析——存绝对路径重装就失效
- 删科目不删卡片，只把卡片变成「未分类」
- 删除都是软删除，进回收站留 30 天，app 启动时清理过期记录和图片
- 标签不建表，就是卡片上的一个字段，候选标签从现有卡片聚合出来

## 怎么构建

需要 Flutter SDK、Android SDK（platform 36 / build-tools 36.0.0 / NDK 28.2）和 JDK 17。

```powershell
flutter pub get
flutter analyze          # 必须零警告
flutter test             # 单元测试 + golden 图比对
flutter build apk --release
```

产物在 `build\app\outputs\flutter-apk\app-release.apk`，手动传进手机安装。

依赖走的是国内镜像（`android/settings.gradle.kts` 和 `android/build.gradle.kts`
里只配了阿里云和 flutter-io 的源）。**不要加回 `google()` / `mavenCentral()` /
`gradlePluginPortal()`**：这台机器上它们极慢，一被回退过去整个构建就会卡住。

## 素材脚本

首页的六张角色贴纸、应用图标、列表页背景的那三个图案，都是
`tools/prepare_assets.py` 从一个源图目录处理出来的。源图不进版本库，
路径通过参数或环境变量给：

```powershell
python tools/prepare_assets.py --source-dir D:\素材\2026-09
```

产物（`assets/` 下的 PNG）要提交进版本库——脚本本身是一次性的，换图时重跑。

## 代码结构

```
lib/
  main.dart              初始化：图片目录 → 数据库 → 清回收站 → 起界面
  app_globals.dart       全局单例（imageStore / cardRepository / subjectCache）
  theme/app_theme.dart   所有视觉参数的唯一出处
  models/                StudyCard、Subject
  data/                  建库、读写、图片仓库、导出、导入
  widgets/               可复用组件（含列表页背景 AppBackground）
  features/<功能>/        每个功能一个目录
```

页面绝不直接写 SQL（一律走 `CardRepository`），也绝不写死颜色和间距
（一律从 `theme/app_theme.dart` 取）。

## 数据怎么带走

首页右上角「更多」→「导出数据」，先挑要导哪些功能、哪些科目（默认全选，
也可以只导「运筹的错题」这种组合），得到一个 zip：里面是选中功能的
Markdown，加一份 `data.json`（科目和卡片全字段）和 `images/` 原图。

换手机时把 zip 传到新手机，同样在「更多」里点「导入数据」：

- **合并导入**：新卡片追加进去，同名科目自动复用，手机上现有的数据一条不动
- **清空后导入**：先删掉现有的全部卡片和图片，整包换成备份里的内容（会再问一次）

导入过程中任何一步出问题都会整体回滚：宁可一条没导进来，也不留半份数据。
回收站里的卡片不参与导出，也不参与导入。
